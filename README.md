# Blinkit Dashboard Analysis 📊

An interactive **Blinkit Sales Analysis Dashboard** developed using **Power BI** to analyze sales performance across different product categories and outlet characteristics.

### 📌 Dashboard Highlights
- Total Sales and Average Sales analysis
- Number of Items and Average Rating
- Sales analysis by **Fat Content**
- Performance analysis by **Item Type**
- Sales trends based on **Outlet Establishment**
- Analysis by **Outlet Location / Tier**
- Sales distribution by **Outlet Size**
- Interactive filters for Outlet Location Type, Item Type, and Outlet Size

### 🛠️ Tools Used
- Power BI
- Power Query
- DAX
- Data Visualization

### 🎯 Objective
The objective of this project is to transform Blinkit sales data into an interactive Power BI dashboard that provides a clear view of product and outlet-level performance and helps identify sales patterns across different business dimensions.
